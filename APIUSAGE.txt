================================================================================
LOVELY ANIME API - FULL API USAGE GUIDE (v3.0)
================================================================================
Base URL: http://127.0.0.1:8000
Interactive docs: http://127.0.0.1:8000/  (home page with API Tester box)
All responses are JSON. All anime ids are AniList ids.

QUICK START
--------------------------------------------------------------------------------
1) Search an anime            GET /anime/search?q=naruto
2) Get info + episodes        GET /anime/1735
3) Get direct MP4 download    GET /download/auto/1735/sub/1
4) Download the file          GET /download/auto/1735/sub/1/file   (browser: just click)

ENDPOINT SUMMARY
--------------------------------------------------------------------------------
 METHOD  PATH                                     WHAT IT DOES
 GET     /                                         Home page + API tester UI
 GET     /anime/search?q={name}                    Search anime (series list)
 GET     /search?query={name}                      Same as above (alias)
 GET     /suggestions?query={name}                 Lightweight autocomplete (max 8)
 GET     /filter?genre=&tag=&year=&...             Advanced filter / browse
 GET     /spotlight                                Top 10 trending + popular
 GET     /trending                                 Currently trending anime
 GET     /popular                                  Most popular of all time
 GET     /upcoming                                 Most anticipated upcoming
 GET     /recent                                   Currently airing this season
 GET     /schedule                                 Airing schedule (next week)
 GET     /info/{anilist_id}                        Full anime metadata (37 fields)
 GET     /anime/{anilist_id}                       INFO + EPISODES in one response
 GET     /anime/{id}/characters                    Paginated characters + voice actors
 GET     /anime/{id}/relations                     Sequels, prequels, side stories
 GET     /anime/{id}/recommendations               Community recommendations
 GET     /episodes/{anilist_id}                    Episode lists from all providers
 GET     /sources?episodeId=&provider=&anilistId=&category=   Raw stream URLs
 GET     /watch/{provider}/{id}/{category}/{slug}  Streams for one episode
 GET     /download/{provider}/{id}/{category}/{n}  Direct MP4 download links (JSON)
 GET     /download/auto/{id}/{category}/{n}        Auto-picks a provider with MP4
 GET     /download/{provider}/{id}/{category}/{n}/file   Streams the MP4 (browser download)

COMMON RESPONSE SHAPE (collections: /trending /popular /upcoming /recent /search /filter)
--------------------------------------------------------------------------------
{
  "page": 1,
  "perPage": 20,
  "total": 5000,
  "hasNextPage": true,
  "results": [ { ...anime fields... } ]
}

================================================================================
3. FILTER / BROWSE - GET /filter
================================================================================
All params optional:
  genre  (e.g. Action, Romance, Comedy)
  tag    (e.g. Isekai, Time Skip)
  year   (e.g. 2024)
  season (WINTER, SPRING, SUMMER, FALL)
  format (TV, MOVIE, OVA, ONA, SPECIAL, MUSIC)
  status (RELEASING, FINISHED, NOT_YET_RELEASED, CANCELLED, HIATUS)
  sort   (SCORE_DESC, POPULARITY_DESC, TRENDING_DESC, START_DATE_DESC, FAVOURITES_DESC, UPDATED_AT_DESC)
  page / per_page (default 1 / 20, max 50)
Example: GET /filter?genre=Action&format=TV&sort=SCORE_DESC&per_page=5

Response: same collection shape as /search (page, perPage, total, hasNextPage, results[]).

================================================================================
4. COLLECTIONS - /trending /popular /upcoming /recent /spotlight /schedule

GET /spotlight                       -> top 10 (trending + popular), no pagination
GET /schedule?page=1&per_page=20     -> airing schedule

================================================================================
6. INFO + EPISODES TOGETHER - GET /anime/{anilist_id}
================================================================================
One call = full info + all providers' episode lists.
Example: GET /anime/1735

Response structure:
{
 "info":     { ...same as /info/1735, 37 fields... },
 "episodes": {
   "mappings": { "id": 18432, "malId": 1735, "aniId": 1735, "kitsuId": 1555, "imdbId": "tt0988824", ... },
   "providers": {
     "ally": { "id": ..., "mapping_id": ..., "provider_id": [...], "episodes": { "sub": [...500...], "dub": [...500...] } },
     "moo":  { ..., "episodes": { "sub": [...497...], "dub": [...497...] } },
     "kiwi": { ..., "episodes": { "sub": [...500...] } },
     "bee", "bonk", "hop", "pewe", ...
   }
 }
}

Each episode entry looks like:
{
 "id": "watch/kiwi/1735/sub/animepahe-1",
 "number": 1,
 "title": "Homecoming",
 "image": "https://...",
 "airDate": "2007-02-15",
 "duration": 1388,
 "description": "...",
 "filler": false
}

The "id" can be used DIRECTLY as a URL for /watch (see section 8).

================================================================================
7. CHARACTERS / RELATIONS / RECOMMENDATIONS
================================================================================
GET /anime/{id}/characters?page=1&per_page=25
  -> { page, perPage, total, hasNextPage, characters: [ { role, node { id, name, image, description, gender, age, favourites, siteUrl }, voiceActors [ { id, name, image, languageV2 } ] } ] }
GET /anime/{id}/relations
  -> { id, title, relations: [ { relationType: "PREQUEL|SEQUEL|SIDE_STORY|SOURCE|...", node { id, title, format, status, episodes, meanScore, ... } } ] }
GET /anime/{id}/recommendations?page=1&per_page=10
  -> { page, perPage, total, hasNextPage, recommendations: [ { rating, mediaRecommendation { id, title, coverImage, format, episodes, status, meanScore, ... } } ] }

================================================================================
8. EPISODES / STREAMS
================================================================================
GET /episodes/{anilist_id}
  Same as the "episodes" part of /anime/{id} (mappings + providers).

GET /sources?episodeId={raw_id}&provider={provider}&anilistId={id}&category={sub|dub}
  Low-level: pass the raw episode id from /episodes.

GET /watch/{provider}/{anilist_id}/{category}/{slug}
  Example: GET /watch/kiwi/1735/sub/animepahe-1
  (take the "id" from /episodes or /anime and use it as the URL)

Response (streams):

  { "url": "https://kwik.cx/e/...", "type": "embed", "quality": "1080p", ... },
  { "url": "https://tools.fast4speed.rsvp/media3/videos/.../sub/1?Authorization=...", "type": "mp4", "quality": null, ... }
 ],

================================================================================
9. DIRECT MP4 DOWNLOADS (THE KEY PART)
================================================================================
GET /download/{provider}/{anilist_id}/{category}/{episode_number}
  -> direct MP4 link(s) for one episode from a SPECIFIC provider (moo, ally, ...)

GET /download/auto/{anilist_id}/{category}/{episode_number}
  -> automatically tries providers (moo -> ally -> bonk -> bee -> kiwi -> pewe -> hop)
     and returns the first one that has an MP4.

Example: GET /download/auto/1735/sub/1
Response:
{
 "anilist_id": 1735,
 "provider": "moo",
 "episode": "animegg:naruto-shippuden:1",
 "download_url": "https://www.animegg.org/play/213281/video.mp4?for=101784113602904",
 "downloads": [
  { "url": "https://www.animegg.org/play/213281/video.mp4?for=101784113602904", "quality": "480p", "resolution": null, "codec": null, "fansub": null },
  { "url": "https://www.animegg.org/play/54112/video.mp4?for=101784113602904",  "quality": "360p", "resolution": null, "codec": null, "fansub": null }
 ]
}

BROWSER DOWNLOAD (no curl needed):
GET /download/{provider}/{anilist_id}/{category}/{episode_number}/file
Example: GET /download/auto/1735/sub/1/file
  -> streams the MP4 through the API with the correct Referer header.
     HTTP 200, Content-Type: video/mp4,
     Content-Disposition: attachment; filename="1735-auto-sub-1.mp4"
  Just open this URL in a browser (or point <a href> at it) to download.

QUALITY SELECTION:
Add ?quality={resolution} to pick a specific quality instead of best:
  GET /download/auto/1735/sub/1/file?quality=360p
  GET /download/auto/1735/sub/500/file?quality=1080p
If the requested quality is not available, it falls back to the best one.
Available qualities are listed in the /download JSON response ("downloads").

PRO TIPS:
- The animegg ?for= token is time-limited: fetch a fresh link from the API
  right before downloading. The /file endpoint always fetches fresh.
- Raw download_url works with curl too, but needs the right Referer:
    curl -L -H "Referer: https://www.animegg.org/" "<download_url>" -o ep.mp4
- ally/fast4speed MP4 links can be stale (401/404) if Miruro's upstream token
  expired — that is an upstream issue; use moo (animegg) or auto.

================================================================================
ERRORS
================================================================================
- 404  "Anime not found" / "Episode slug '...' not found for provider ..."
- 404  {"message": "No direct MP4 download found on any provider", "attempts": [...]}
- 500  "AniList query failed"            (upstream AniList problem)
- non-200 from Miruro pipe              (Cloudflare / upstream problem)

EXAMPLE FLOW (Naruto Shippuden episode 1)
================================================================================
1. Search:
   GET /anime/search?q=naruto shippuden
   -> id = 1735

2. Info + episodes:
   GET /anime/1735
   -> providers -> kiwi -> episodes -> sub -> [0].id = "watch/kiwi/1735/sub/animepahe-1"

3. Direct MP4 links:
   GET /download/auto/1735/sub/1
   -> download_url = "https://www.animegg.org/play/213281/video.mp4?for=..."

4. Download the file (browser):
   GET /download/auto/1735/sub/1/file
   -> saves 1735-auto-sub-1.mp4 (70 MB, 480p, verified valid MP4)

================================================================================
BATCH DOWNLOADER SCRIPT (download_season.py)
================================================================================
Download a whole season at a chosen quality through the /file endpoint.
Requires the API to be running (default http://127.0.0.1:8000).

  python download_season.py --id 1735                         # all 500 eps, best quality
  python download_season.py --search "naruto shippuden"       # resolve the id from a search
  python download_season.py --id 1735 --quality 480p          # pick a quality (360p/480p/720p/1080p)
  python download_season.py --id 1735 --dub --quality 720p    # dubbed audio
  python download_season.py --id 1735 --start 1 --end 24 -o naruto-s01   # one cour
  python download_season.py --id 1735 --dry-run               # list the URLs without downloading
  python download_season.py --id 1735 --force                 # re-download even if files exist

Features:
- Names files by episode + the quality actually served:
    NARUTO Shippuuden - E001 - 360p.mp4
- Skips already-downloaded episodes on re-run (resume-safe); stale .part
  files from interrupted runs are cleaned up automatically.
- Per-episode progress (bytes + speed), 3 retries with backoff, 0.5s delay
  between episodes by default, summary at the end, exit code 1 if any failed.
- --search prints a numbered result list; use --pick N to choose a match.
